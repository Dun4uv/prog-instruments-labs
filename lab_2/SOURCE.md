# Источник кода для лабораторной работы №2

Для ревью я выбрал программу на Python, которая обрабатывает
анкеты и проверяет телефонные номера. Код взят из репозитория
[Autom4k/prog-instruments-labs](https://github.com/Autom4k/prog-instruments-labs).

Исходный файл: `lab_1/lab1_var18.py`, ветка `lab1`.

Для работы выбрана версия из коммита
`31db1f33ac0c2ee8973537abf317a1e29ce76aee`:
[посмотреть исходник](https://github.com/Autom4k/prog-instruments-labs/blob/31db1f33ac0c2ee8973537abf317a1e29ce76aee/lab_1/lab1_var18.py).

В моём репозитории копия программы находится в
`lab_2/lab1_var18.py`. Код сохранён без изменений, чтобы
замечания относились к исходной версии. Найденные проблемы
и предложения по исправлению будут описаны в комментариях
к Pull Request.

Исходный репозиторий использует лицензию MIT. Её копия
сохранена рядом с программой в файле `ORIGINAL_LICENSE`.
